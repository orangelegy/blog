1. 文件权限概念

Linux是多用户系统，每个文件都有所有者(owner)和所属组(group)，通过权限机制保护文件安全。

查看文件属性：

输出7个字段：

  1. 权限(10字符) | 2. 链接数 | 3. 所有者 | 4. 所属组 | 5. 大小 | 6. 修改时间 | 7. 文件名

2. 权限字段详解

第1字符：文件类型

  • -：普通文件
  • d：目录
  • l：符号链接
  • b：块设备
  • c：字符设备

第2-10字符：权限三组

  • u：所有者(user)
  • g：所属组(group)
  • o：其他人(others)

权限字符：

  • r：读(read)
  • w：写(write)
  • x：执行(execute)
  • -：无权限

3. 数字表示法

权限 数字 含义
r 4 读
w 2 写
x 1 执行
- 0 无

常用组合：

  • 7 = rwx (4+2+1)
  • 6 = rw- (4+2)
  • 5 = r-x (4+1)
  • 4 = r–
  • 0 = —

三位数字： chmod 754 file

  • 7(所有者): rwx
  • 5(组): r-x
  • 4(其他人): r–

5. 文件与目录权限区别

权限 对文件意义 对目录意义
r 查看内容(cat) 列出内容(ls)
w 修改内容(vim) 增删文件(touch/rm)
x 执行文件(./) 进入目录(cd)

目录权限铁律：

  • 有 x 才能 cd 进入
  • 有 r 才能 ls 列出
  • 有 w 才能创建/删除文件(必须同时有x)

6. 修改所有者和组

限制： 普通用户不能改所有者(需root)，只能改自己所属的组

7. 默认权限 umask

  • 文件默认最大：666 (rw-rw-rw-)
  • 目录默认最大：777 (rwxrwxrwx)
  • 最终权限 = 最大权限 - umask

8. 特殊权限

权限 数字 符号 作用
SUID 4 u+s 执行时拥有所有者权限(passwd)
SGID 2 g+s 文件:继承组权限; 目录:新文件继承组
SBIT 1 o+t 仅所有者可删除文件(/tmp)

显示：

  • SUID: -rwsr-xr-x (所有者x变s)
  • SGID: -rwxr-sr-x (组x变s)
  • SBIT: drwxrwxrwt (其他人x变t)

10. FHS目录标准

根目录(/)必须存在：

目录 用途
/bin 一般用户命令(ls, cp)
/boot 启动引导文件(内核)
/dev 设备文件
/etc 系统配置文件
/lib 函数库
/sbin 系统管理命令
/tmp 临时文件

其他重要目录：

目录 用途
/home 用户家目录
/root root家目录
/opt 第三方软件
/usr 系统资源
/var 日志、缓存等可变数据

/usr子目录：

  • /usr/bin：用户命令
  • /usr/sbin：系统命令
  • /usr/lib：函数库
  • /usr/local：本地软件
  • /usr/share：共享文档
  • /usr/src：源代码

/var子目录：

  • /var/log：日志文件
  • /var/mail：邮件
  • /var/spool：队列
  • /var/tmp：临时文件(重启保留)

11. 常用安全权限

类型 权限 说明
普通文件 644 rw-r–r–
目录 755 rwxr-xr-x
脚本 755 rwxr-xr-x
私密文件 600 rw——-
临时目录 1777 rwxrwxrwt

最小权限原则： 只给必要的权限

12. 本章重点命令

命令 用途 示例
ls -l 查看权限 ls -la
chmod 修改权限 chmod 755 file
chown 改所有者 chown user:group file
chgrp 改所属组 chgrp group file
umask 默认权限 umask 002
chattr 隐藏权限 chattr +i file
lsattr 查看隐藏权限 lsattr file
file 查看文件类型 file /bin/ls

一句话总结

权限 = 谁(u/g/o) + 做什么(r/w/x) + 在哪里(文件/目录)，遵循最小权限原则，目录需x才能进入，文件权限看内容操作。
