1. Shell 脚本是什么

1.1 什么是 Shell Script

Shell 脚本（shell script）是利用 shell 的功能所写的一个“程序”，这个程序是使用纯文本文件，将一些 shell 的语法与命令（含外部命令）写在里面，搭配正则表达式、管道命令与数据流重定向等功能，以达到我们所想要的处理目的。

简单来说，Shell 脚本就是将多个命令写在一个文件里，让系统按顺序执行，类似于 DOS 时代的批处理文件（.bat），但功能更强大。

1.2 为什么要学习 Shell 脚本

① 自动化管理

系统管理员每天需要处理大量重复性工作（如分析日志、监控系统、备份数据），通过 shell 脚本可以自动化完成这些任务，大幅提升效率。

② 简化复杂操作

当需要执行一连串复杂的命令时，将这些命令写入脚本，以后只需执行一个文件即可，避免手动输入错误。

③ 可移植性好

只要是 Unix-like 系统（Linux、BSD、macOS），几乎都可以执行 shell 脚本，无需修改。

④ 作为其他语言的基础

学习 shell 脚本可以帮助理解程序流程控制（变量、循环、条件判断），为后续学习 Python、Perl 等语言打下基础。

1.3 Shell 脚本的执行方式区别

执行方式 语法 特点
直接执行（子进程） ./script.sh 需要可执行权限，在子进程中运行，不影响父进程
bash 执行（子进程） bash script.sh 无需可执行权限，在子进程中运行
source 执行（父进程） source script.sh 或 . script.sh 在父进程中直接执行，变量修改会影响当前环境

重要理解：直接执行和 bash 执行都是在子进程中运行脚本，脚本中设置的变量在脚本执行完毕后就会消失；而 source 执行是在当前 shell 进程中运行，变量会保留在当前环境中。这也是为什么修改 ~/.bashrc 后需要用 source ~/.bashrc 使其生效。

1.4 Shell 脚本的创建与执行

建立步骤：

  1. 新建纯文本文件（以 .sh 为扩展名）
  2. 第一行标明使用的 shell：#!/bin/bash
  3. 编写脚本内容（命令、注释等）
  4. 添加可执行权限：chmod +x script.sh
  5. 执行脚本：./script.sh

2.2 脚本执行方式的差异

使用 ./script.sh 和 source script.sh 执行的差异在于：变量是否会在父进程中保留。

测试示例：

  • 执行 ./test.sh：子进程中执行，执行完毕后 $name 变量消失
  • 执行 source test.sh：当前进程中执行，执行完毕后 echo $name 仍然输出 “John”

9. 核心要点

9.1 Shell 脚本的本质

  • Shell 脚本是将多个命令组织在一个文件中的程序，实现自动化管理
  • 通过 source 执行时，脚本在父进程中运行，变量会保留

9.2 判断式核心语法

  • test 命令或 [ ] 进行条件判断，中括号两端必须有空格
  • $? 获取上一条命令的执行结果（0 代表成功）
  • 数值比较用 -eq、-ne、-gt、-lt，字符串用 =、!=

9.3 循环的使用场景

  • while：适合条件未知的循环（如等待用户输入）
  • until：与 while 相反，适合直到某个条件满足才停止
  • for：适合已知循环次数的场景（如遍历文件列表）

9.4 调试技巧

  • 使用 sh -x script.sh 逐行查看执行过程，是排查脚本问题的最有效方法
  • 先用 sh -n 检查语法错误，再用 sh -x 调试逻辑

9.5 学习建议

  • 从简单脚本开始练习，逐步增加复杂度
  • 多参考系统已有的脚本（如 /etc/init.d/ 下的服务脚本）
  • 调试时善用 echo 输出中间变量值
